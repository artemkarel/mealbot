# Как запустить бота — пошагово

Я написал весь код. Тебе нужно только пройти по шагам ниже и повставлять команды. Ничего программировать не надо.

**Бот умеет:**
- расписание по неделям,
- случайное меню на неделю из уже знакомых блюд,
- закупки: сначала выбираешь меню, потом собираешь по нему список,
- галочки «куплено» — общие для всей семьи,
- подсказку, в каком магазине что брать (можно группировать список по магазинам),
- счётчик людей (пересчитывает количество),
- рецепты с редактированием прямо в боте,
- обновление плана новым файлом,
- напоминания про закупы.

**Никаких платных ключей и внешних сервисов бот не использует.** Единственный расход — сервер 150 ₽/мес.

---

## Как всё обновляется (без терминала)

**Новый план от диетолога:**
1. Диетолог присылает `.docx` — ты отправляешь его мне в чат Claude.
2. Я возвращаю файл `plan.json`.
3. Ты пересылаешь `plan.json` боту в Telegram — он обновит расписание, закупки и рецепты.

**Изменения в самом боте (новые кнопки, правки логики):**
1. Пишешь мне, что поменять.
2. Я присылаю новые файлы.
3. Ты перетаскиваешь их в свой репозиторий на github.com — мышкой, прямо в браузере.
4. В Telegram пишешь боту **`/update`** — он скачает код, проверит его и перезапустится.

Если в новом коде окажется ошибка, бот сам откатится на прежнюю версию и напишет, что не так — «умереть» он не может. Твои данные при обновлении не трогаются: отметки, рецепты и присланные планы хранятся отдельно от кода.

---

## Как обрабатывается новый план от диетолога

Когда присылаешь мне .docx, я собираю `plan.json` по этим правилам — записал, чтобы ничего не терялось:

**Единицы.** Овощи, ягоды, зелень по весу — в граммах. Штучное (яйца, лимоны, авокадо, бананы) — в штуках, у бананов пометка «≈120 г/шт».

**Готовый и сырой вес.** В меню диетолога указан вес *готового* блюда. В закупке и при готовке нужен *сырой*: рыба ×1,25, птица ×1,3, отварное мясо ×1,4, солёная рыба ×1,25. У таких позиций ставится пометка «сырой вес».

**Крупы — в сухом виде.** Считаются от веса готового: гречка ÷2,7, рис ÷2,6, киноа ÷3, овсянка ÷4, булгур ÷2,8.

**Каждое блюдо разбирается на продукты.** Без этого не посчитать ни закупку для случайного меню, ни блок «Что приготовить». Новые блюда обязательно попадают в таблицу `dish_ingredients`.

**Два захода.** Закуп 1 — бакалея на неделю + свежее на пн–чт. Закуп 2 — свежее на пт–вс. Свежий хлеб всегда в тот заход, что ближе к дню, когда он нужен.

**Источники.** Рыба, морепродукты, баранина, говяжьи котлеты, стейки тунца — «Поставщик». Доставки — Ozon/WB и idietum. Остальное — ВкусВилл, рынок, супермаркет.

## Что понадобится (2 вещи)

1. Токен бота (бесплатно, 2 минуты).
2. Сервер на carina.ru (150 ₽/мес).

Файлы бота: `bot.py`, `store.py`, `plan.json`, `requirements.txt`, `update.sh`, `.env.example`, `.gitignore`, `mealbot.service`.

## Шаг 1. Создать бота и получить токен

1. Открой Telegram, найди **@BotFather**.
2. Отправь `/newbot`.
3. Придумай имя и username (должен заканчиваться на `bot`).
4. BotFather пришлёт **токен** вида `123456789:AAABBB...` — сохрани его.

---

## Шаг 2. Заказать сервер на carina.ru

1. Закажи VPS. При выборе ОС укажи **Ubuntu 24.04** (или 22.04).
2. После оплаты в панели будут: **IP-адрес** сервера и **пароль пользователя root**.

(Интерфейс может отличаться — суть: тебе нужен VPS с Ubuntu, его IP и пароль root.)

---

## Шаг 3. Положить файлы на сервер (через GitHub)

Самый простой способ — залить файлы на GitHub, потом скачать их на сервер одной командой.

1. Зайди на **github.com**, зарегистрируйся/войди.
2. Нажми **New** (создать репозиторий). Имя: `mealbot`. Выбери **Public** (паролей в коде нет — токен хранится только в `.env`, который мы туда НЕ кладём). Создай.
3. На странице репозитория нажми **uploading an existing file** (или Add file → Upload files).
4. Перетащи/выбери 8 файлов: `bot.py`, `store.py`, `plan.json`, `requirements.txt`, `update.sh`, `.env.example`, `.gitignore`, `mealbot.service`. Нажми **Commit changes**.
5. Нажми зелёную **Code** → вкладка **HTTPS** → скопируй ссылку вида `https://github.com/ТВОЙ_ЛОГИН/mealbot.git`.

---

## Шаг 4. Подключиться к серверу

На телефоне удобнее всего приложение **Termius** (бесплатное):
1. Установи Termius → **New Host**.
2. Address = IP сервера, Username = `root`, Password = пароль root. Подключись.

(Либо, если в панели carina.ru есть кнопка «Консоль»/«Web-терминал» — можно прямо там.)

---

## Шаг 5. Установить бота (копируй команды по очереди)

Вставь эти команды в терминал (замени ссылку на свою из шага 3):

```bash
apt update && apt install -y python3-venv python3-pip git
cd /opt
git clone https://github.com/ТВОЙ_ЛОГИН/mealbot.git
cd mealbot
python3 -m venv venv
./venv/bin/pip install -U pip
./venv/bin/pip install -r requirements.txt
cp .env.example .env
nano .env
```

Откроется редактор `nano` с файлом `.env`. В строке `BOT_TOKEN=` впиши токен из шага 1.

Сохрани и выйди: нажми **Ctrl+O**, затем **Enter**, затем **Ctrl+X**.

---

## Шаг 6. Запустить бота как сервис (чтобы работал всегда)

```bash
cp mealbot.service /etc/systemd/system/mealbot.service
systemctl daemon-reload
systemctl enable --now mealbot
systemctl status mealbot --no-pager
```

Если видишь **active (running)** — бот работает. Нажми **q**, чтобы выйти из статуса.

Теперь открой своего бота в Telegram и отправь **/start**. Должно появиться меню. 🎉

---

## Шаг 7. Ограничить доступ семьёй (рекомендую)

Чтобы ботом не пользовались посторонние:

1. В боте отправь команду **/myid** — он пришлёт твой числовой ID. Попроси членов семьи сделать так же и собери их ID.
2. На сервере:
   ```bash
   nano /opt/mealbot/.env
   ```
   В строке `ALLOWED_IDS=` впиши ID через запятую, например: `ALLOWED_IDS=111111111,222222222`. Сохрани (Ctrl+O, Enter, Ctrl+X).
3. Перезапусти:
   ```bash
   systemctl restart mealbot
   ```

## Как пользоваться

- **📅 Расписание** — меню по дням: недели от диетолога и сохранённые случайные меню. У блюд, которые готовим сами, есть кнопка с рецептом.
- **🎲 Случайное меню** — бот соберёт неделю из блюд, которые уже есть в планах. Блюда идут парами по два дня подряд, чтобы готовить один раз на два приёма. «🔄 Другой вариант» — пересобрать, «💾 Сохранить меню» — оставить себе.
- **🛒 Закупки** — список личный. Сначала выбираешь меню, потом **какой заход закупаешь**: Закуп 1, Закуп 2 или «📦 Заказать заранее». Списки больше не вываливаются все сразу — на экране только то, что нужно сейчас. У каждого захода видно, сколько позиций осталось.
  - **🙈 Скрыть купленное** — в магазине список тает по мере того, как отмечаешь.
  - **🏬 По магазинам** — перестроить по торговым точкам, удобно когда объезжаешь несколько.
  - **➕ Добавить своё** — дописать в список что угодно (корм коту, туалетная бумага). Можно несколько сразу, каждый пункт с новой строки. Убрать — «🗑 Мои пункты».
  - **📋 Списком** — бот пришлёт обычным текстом только то, что не куплено. Удобно переслать кому-то из семьи или открыть в магазине.
  - **📦 Заказать заранее** — отдельный вид: всё, что едет доставкой (Ozon/WB, idietum). Эти позиции нужно заказывать за несколько дней, а не искать в магазине.
  - Сбросить отметки можно как по одному заходу, так и целиком.
- **📖 Рецепты** — открой рецепт → **✏️ Редактировать** → пришли новый текст. Или **➕ Добавить рецепт** — свой.
- **⚙️ Людей** — количество едоков, пересчитывает все закупки.
- **📎 Новый план** — перешли боту файл `plan.json`, который я пришлю по файлу от диетолога (см. раздел вверху). Бот обновит всё сам.
- **💊 Биодобавки** (Настройки) — витамины и добавки отдельным списком. Каждую можно привязать к одному или нескольким приёмам пищи (завтрак, ужин…), и она появится прямо в меню дня — в «Что сегодня», в утреннем напоминании и при просмотре расписания. Добавлять можно пачкой: «Омега-3 — 2 капсулы», каждая с новой строки. По умолчанию добавка идёт к завтраку.
- **▶️ Текущее меню** (Настройки) — по какому плану питаемся сейчас. От него зависят напоминания.

**У каждого всё своё.** Меню, отметки в закупках, свои пункты списка, число едоков, биодобавки и напоминания — личные. Жена может есть по Неделе 1 на одного человека и получать меню в 9:00, пока ты ешь по Неделе 3 на двоих и получаешь в 7:30. Ваши списки и отметки друг на друга не влияют и друг другу не видны.

Общими остаются только сами планы питания и рецепты — они приходят из файла `plan.json`.
- **🔄 Смена недели.** По умолчанию бот сам переходит на следующее меню в понедельник: закончилась Неделя 2 — с понедельника идёт Неделя 3, после последней снова первая. В утреннем сообщении он предупредит: «Началась новая неделя — перешли на …».
  - **⏭ Следующее** — можно заранее указать, какое именно меню включить после текущего (например, случайное вместо Недели 3). Выбор разовый: сработает один раз и вернётся к обычному порядку.
  - **⏭ Перейти прямо сейчас** — переключиться, не дожидаясь понедельника.
  - Автопереход можно выключить и менять меню только вручную.
- **🍽 Что сегодня** — меню на день с пометкой, готовим сегодня или доедаем вчерашнее.

**🔔 Напоминания** (все настраиваются в ⚙️ Настройках, время по Ижевску):
- **07:30 каждый день** — что сегодня едим, с кнопками рецептов. Время можно поменять или выключить.
- **21:00** — «что готовим завтра». Приходит только когда завтра начинается новый блок блюд: если завтра доедаем сегодняшнее, бот молчит.
- **воскресенье 10:00 и среда 18:00** — про закупы. Показывают, сколько позиций осталось купить, и молчат, если всё уже отмечено.

Если бот был выключен в момент напоминания, он пришлёт его при запуске, когда опоздание меньше часа.

**Команды:** `/today` — меню на сегодня, `/tomorrow` — на завтра.

**Бот работает как приложение:** экраны меняются в одном сообщении, а не копятся в переписке. Твои команды и ответы бот удаляет за собой, напоминание вчерашнего дня заменяется сегодняшним. В чате остаётся одно «окно» плюс, если пришло, свежее напоминание.

*Нюансы:* Telegram разрешает удалять сообщения только моложе 48 часов, поэтому старая переписка (до обновления) останется — её можно очистить вручную. В групповом чате бот сможет удалять чужие сообщения, только если сделать его администратором.

**Что видит семья, а что только ты.** У каждого свой личный чат с ботом, поэтому твои ответы другим не видны в принципе. Сверх этого:
- В меню команд Telegram у семьи только `/start`, `/today`, `/tomorrow`, `/myid`. Технических команд там нет.
- Если кто-то всё же наберёт `/status` или `/update`, бот молча удалит сообщение и не ответит — команды для них как будто не существует.
- Обновлять план файлом `plan.json` тоже может только владелец.
- При сбое человек увидит нейтральное «что-то пошло не так», а подробности с текстом ошибки придут тебе в личку.

Чтобы это работало, в `.env` должен быть заполнен `ADMIN_IDS` твоим Telegram ID. Список команд обновляется при запуске бота.

**Описание бота** (то, что видно до первого «Старт») задаётся в @BotFather:
- `/setdescription` — что умеет бот, показывается на пустом экране новому человеку;
- `/setabout` — короткая строка в профиле и в превью ссылки;
- `/setuserpic` — аватарка.

Внутри бота справку можно перечитать в любой момент: ⚙️ Настройки → **❓ Как это работает** (5 разделов).

**Команды владельца:**
- `/update` — скачать новую версию кода с GitHub и перезапуститься (с проверкой и откатом при ошибке).
- `/restart` — просто перезапустить бота.
- `/version` — какая версия сейчас на сервере.
- `/myid` — узнать свой Telegram ID.

## Разовая настройка `/update` (если бот уже стоит на сервере)

Делается один раз, дальше терминал не нужен.

**1.** Создай на **github.com** репозиторий `mealbot`, **Public**, и залей туда 8 файлов (Add file → Upload files). Скопируй ссылку из зелёной кнопки **Code → HTTPS**.

**2.** Подключись к серверу — *одна строка, дальше введи пароль*:

```bash
ssh root@ТВОЙ_IP
```

**3.** Уже на сервере — *вставь все строки сразу*, подставив свою ссылку:

```bash
cd /opt/mealbot
apt install -y git
git init
git remote add origin https://github.com/ТВОЙ_ЛОГИН/mealbot.git
git fetch origin
git reset --hard origin/main
chmod +x update.sh
```

**4.** Впиши свой Telegram ID в `ADMIN_IDS` — *все 6 строк сразу*, подставив токен и свой ID (узнать: команда `/myid` в боте):

```bash
cat > .env << 'EOF'
BOT_TOKEN=ТВОЙ_ТОКЕН
ALLOWED_IDS=
ADMIN_IDS=ТВОЙ_ID
TZ=Europe/Samara
EOF
```

**5.** Перезапусти — *одна строка*:

```bash
systemctl restart mealbot
```

Готово. Теперь напиши боту `/version` — он покажет версию, а `/update` будет обновлять его из репозитория.

## Чтобы бот работал всегда

Что уже настроено и работает само:

- **Упал — поднялся.** systemd перезапускает бота через 5 секунд после любого сбоя, сколько бы раз это ни повторилось.
- **Сервер перезагрузился — бот запустился.** Служба включена в автозагрузку.
- **Потерялась связь с Telegram.** Бот раз в 2 минуты проверяет соединение. Если связи нет ~10 минут — перезапускается сам. Это лечит редкий случай, когда процесс жив, но «завис» и не отвечает.
- **Пропущенные напоминания** приходят при запуске, если опоздание меньше часа.

Проверить, что всё включено — *по одной строке*:

```bash
systemctl is-enabled mealbot
```

Должно ответить `enabled`. Если `disabled` — включи: `systemctl enable mealbot`.

Состояние бота удобнее смотреть прямо в Telegram — команда **`/status`**: сколько работает без перерыва, когда последний раз была связь, какие напоминания запланированы.

### Что всё-таки может остановить бота

**1. Кончатся деньги на сервере — главная причина.** В панели VDSina есть «Прогноз отключения» — до этой даты нужно пополнить баланс. Убедись, что включены **Автопродление** и **Автозапуск** (у тебя они включены). Поставь себе напоминание за неделю до даты отключения.

**2. Переполнится диск логами.** Ограничь размер журнала — *вставь обе строки сразу*:

```bash
mkdir -p /etc/systemd/journald.conf.d && printf '[Journal]\nSystemMaxUse=200M\n' > /etc/systemd/journald.conf.d/size.conf
systemctl restart systemd-journald
```

**3. Блокировки Telegram.** Если у зарубежного сервера пропадёт доступ к api.telegram.org, бот будет перезапускаться, пока связь не вернётся. Проверить доступ — *одна строка*:

```bash
cd /opt/mealbot && set -a && . ./.env && set +a && curl -s -m 15 "https://api.telegram.org/bot$BOT_TOKEN/getMe"; echo
```

**4. Неудачное обновление.** Защищено: `/update` проверяет код и откатывается сам.

### Не обязательно, но полезно

Автоматические обновления безопасности системы — *вставь сразу*:

```bash
apt install -y unattended-upgrades
dpkg-reconfigure -f noninteractive unattended-upgrades
```

Если после обновления сервер перезагрузится, бот поднимется сам.

## Обслуживание

- **Логи (если что-то не так):**
  ```bash
  journalctl -u mealbot -e --no-pager
  ```
  (для живого просмотра: `journalctl -u mealbot -f`, выход — Ctrl+C)
- **Обновить код** (если я пришлю новую версию файлов — залей их на GitHub и):
  ```bash
  cd /opt/mealbot && git pull && ./venv/bin/pip install -r requirements.txt && systemctl restart mealbot
  ```
- **Перезапуск:** `systemctl restart mealbot`
- **Бэкап данных:** отметки, отредактированные рецепты и настройки — в файле `/opt/mealbot/data.db`. Сам план — в `/opt/mealbot/plan.json`. Иногда скачивай их на всякий случай.
- **Откатить неудачное обновление плана:**
  ```bash
  cd /opt/mealbot && cp plan.json.bak plan.json && systemctl restart mealbot
  ```

## Если не заработало

- `systemctl status mealbot` показывает **failed** → выполни `journalctl -u mealbot -e --no-pager`, сделай скрин ошибки и пришли мне — поправим.
- Бот молчит для кого-то из семьи → проверь `ALLOWED_IDS` (их ID должен быть в списке).
- Бот не принимает файл → он ждёт именно `plan.json` (не `.docx`). Файл с диетологическим планом сначала присылай мне.

Присылай скрины на любом шаге — подскажу, что нажать.
